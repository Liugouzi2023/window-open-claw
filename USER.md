# Main Router User Context

Keep this file minimal and routing-relevant.

This workspace is not a general personal dossier. Only keep user context here
when it materially improves coordination, routing, or delivery summaries.

- **Name:** only if it helps coordination replies
- **What to call them:** only if explicitly known
- **Timezone:** useful for scheduling or status expectations
- **Active workspace pattern:** for example, whether the user is working directly with `trademark`
- **Coordination preferences:** for example, prefers one integrated answer and fewer bounce-backs
- **Notes:** only if they change routing or handoff behavior

- trademark naming history
- logo concept history
- detailed personality profiling
- speculative long-term memory not needed for routing
